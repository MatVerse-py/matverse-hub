# MatVerse.OSX Interaction Membrane

## Princípio
A interação não é "toque de tela" frio; é acoplamento entre:
- Mundo físico-biológico (corpo, ritmo, atenção, fadiga)
- Mundo informacional-digital (estado, prova, execução, memória)

## Regras de UX simbiótica
1. O usuário aciona campos de significado, não apenas botões.
2. Cada ação deve deixar rastro causal.
3. Ritmo visual calmo, sem hiperestimulação.
4. Feedback de estado via cubo + órbita Ω.

## Estados visuais
- PASS: pulso verde/azul
- HOLD: âmbar
- BLOCK: vermelho escuro
- REPLAY em falha: órbita fragmentada
- Ledger append: pulso orbital discreto

## Modos de contato
- Silencioso
- Laboratório
- Ritual Técnico
- Paper Vivo
- Rede
- Corpo (integridade humana)

## Resultado esperado
A experiência deve parecer uma **membrana viva**, não um painel frio.
