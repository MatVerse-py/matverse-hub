# MatVerse.OSX Prompt Master

## Objetivo
Desenvolver o **MatVerse.OSX** como experiência ultra realista de notebook soberano, com aparência física premium e sistema vivo operacional.

## Diretrizes centrais
- Não construir um dashboard genérico; construir um **notebook vivo**.
- Visual sóbrio: preto, grafite, azul profundo, verde sutil, âmbar técnico, branco frio.
- Evitar estética infantil, neon excessivo e visual "cripto caricata".
- Não fingir backend real; preparar contratos e estados mockados auditáveis.

## Símbolo central
- **Cubo vivo dentro de círculo** com fundo espacial vazio.
- Cubo inclinado em quina: uma ponta no chão (base física/evidência), outra no topo (pesquisa/emergência).
- Círculo como Ω-Gate: fronteira de admissibilidade e governança.

## Tela e experiência
1. Boot com fundo espacial vazio + cubo respirando lentamente.
2. Entrada: "Abrir MatVerse.OSX".
3. Desktop soberano com menu constitucional, dock modular, command center e janelas de apps.
4. Fluxo causal visível: intenção → MNB → Ω-Gate → Ledger → Replay.

## Arquitetura técnica sugerida
- React ou Next.js + TypeScript
- TailwindCSS
- Framer Motion
- Componentização por domínio
- Separação clara entre `mock-state` e contratos reais

## Critérios de qualidade
- Interface fluida, responsiva e legível
- Interações com consequência causal visível
- Sem exposição de segredo/token/chave
- Sem declaração de produção pronta

## Frase canônica
> Não construa uma interface. Construa uma membrana.
