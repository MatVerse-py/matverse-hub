# MatVerse.OSX Final Architecture

## Visão em camadas

### L0 — Máquina soberana
Hardware, TPM, storage cifrado, secure boot, base OS.

### L1 — OS + experiência
- MatVerse.OS (constituição e invariantes)
- Symbios.OS (runtime e agentes)
- MatVerse.OSX (UX/desktop)

### L2 — Governança ACOA
Body-D → Body-A → Body-X com decisão via Ω-Gate.

### L3 — Pipeline causal IQG
PRIMORDIAL → SVCA → MNB → MOTOR → LEDGER.

### L4 — Prova e continuidade
Replay, Evidence Pack, PoSE/PoLE e Paper Vivo.

### L5 — Rede e nós
Notebook local, servidor, Symbiodroid, QeX node, witness, anchors.

### L6 — Domínios
Científico, econômico, saúde, segurança, política e governança.

## Regra canônica
Tudo que vira prova precisa de **hash + receipt + ledger + replay**.

## Separação estrutural TACE × GOV
- **TACE**: ciência aplicada, controle de risco de IA, coerência e benchmark.
- **GOV**: orquestração institucional B2G, protocolo, identidade, auditoria.
- Integração apenas via kernel compartilhado controlado (receipt/ledger/policy/hash/merkle).
